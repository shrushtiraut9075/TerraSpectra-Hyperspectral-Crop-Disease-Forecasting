# Frontend Spec — TerraSpectra GIS Dashboard (React + Deck.gl)

## 1. Purpose

A professional agricultural intelligence interface: pick a field and date, see disease-risk heatmaps draped on 3D terrain, read analytics, and scrub through time.

## 2. Stack

- React 18 + TypeScript + Vite
- Deck.gl 9 (`@deck.gl/react`, `core`, `layers`, `geo-layers`) over **MapLibre GL** (Mapbox optional via env token)
- TanStack Query (server state), Zustand (UI state)
- Recharts or Plotly.js for charts
- Tailwind CSS for layout; Vitest + React Testing Library; Playwright for one smoke flow

## 4. Components

| Component | Responsibility |
|---|---|
| `MapView` | Deck.gl + MapLibre canvas, camera state, terrain, tooltips |
| `RiskLayer` | `TileLayer` + `BitmapLayer` using the API's XYZ PNG tiles; opacity control |
| `ZonesLayer` | `GeoJsonLayer` outlines, fill by `mean_risk`, click to select zone |
| `SceneList` | Lists scenes for the field, shows acquisition date and status |
| `ThresholdControl` | Slider 0–1 (default 0.5); refetches zones/analytics (debounced) |
| `RunInferenceButton` | Starts job, shows progress bar from `GET /jobs/{id}` polling |
| `AnalyticsPanel` | Big number: acres at risk; percent of field; zones count |
| `AnomalyChart` | Bar chart of anomaly shares (hidden if API returns none) |
| `RiskHistogram` | Distribution of risk scores |
| `TimelineSlider` | Date steps from `/fields/{id}/timeline`; play/pause; keyboard arrows |
| `TrendSparkline` | Acres at risk over time with current date marked |
| `DataOriginBadge` | Always visible: SYNTHETIC / PUBLIC / REAL |
| `ErrorBoundary`, `EmptyState`, `Skeleton` | Robustness and polish |

## 5. Map and GIS Requirements (Mid-Project Gate)

- Camera initial fit: `bounds_wgs84` of the selected scene via `fitBounds`.
- Heatmap raster positioned **only** from API-provided bounds / XYZ tiles; **no hardcoded coordinates** in code.
- 3D: enable terrain (raster-dem source such as an open DEM tileset) with exaggeration slider, or tilt/pitch 45–60° over a satellite or neutral base. Heatmap must remain aligned when pitched and rotated.
- **Alignment evidence:** a debug overlay (toggle) draws markers at the 3+ ground control points returned by the synthetic scene metadata; they must sit on the matching features of the raster at several zoom levels. Capture screenshots as review evidence.
- Colour ramp: perceptually ordered green → yellow → orange → red; colour-blind-safe alternative toggle. Transparent for risk below threshold.

## 6. Data Fetching

- `GET /fields/{id}/timeline` on field change.
- `GET /scenes/{id}/results/latest` on scene change; tiles loaded lazily by Deck.gl.
- `GET /scenes/{id}/analytics?threshold=` and `zones.geojson?threshold=` debounced 250 ms.
- Polling: `GET /jobs/{id}` every 1 s while `queued|running`, stop on terminal state.
- Never fetch per-pixel JSON; large rasters only as tiles.

## 7. UX Details

- Hover a zone: tooltip with zone id, area (acres), mean/max risk.
- Click a zone: right panel scrolls to that zone row; map flies to it.
- Timeline play: advance one acquisition per 1.2 s, preloading the next scene's tiles.
- Compare mode (stretch): split view between two dates.
- Loading: skeletons, not spinners that block the map.
- Empty state: "No inference yet for this scene — Run inference."
- Natural-language summary line (Week 4): e.g., "4.8% of the field (48 acres) shows early stress signatures; largest zone 12.1 acres in the north-east." Generated by deterministic templates from analytics JSON (not an LLM) so numbers are always correct.

## 8. Visual Design

- Dark, data-first UI: near-black slate background, one accent (agricultural green) plus the risk ramp reserved for data only.
- Typography: a clean sans for UI, tabular numerals for figures.
- Spacing scale 4/8/12/16/24; panels 320 px wide on desktop; collapse to drawers below 1024 px.
- Keep chrome minimal so the map dominates; no more than one accent colour outside the risk ramp.
- Accessibility: focus rings, keyboard timeline control, ARIA labels on sliders, sufficient contrast, reduced-motion respects `prefers-reduced-motion`.

## 9. State Shape (Zustand)

```ts
type UIState = {
  fieldId: string | null
  sceneId: string | null
  threshold: number          // 0..1
  layers: { risk: boolean; zones: boolean; gcps: boolean; terrain: boolean }
  opacity: number
  selectedZoneId: number | null
  playing: boolean
}
```

## 10. Performance Targets

- 60 fps pan/zoom with risk tiles and zone outlines.
- Zones GeoJSON under ~2 MB (server simplifies polygons).
- First meaningful map paint under 2 s on localhost.
- Memoize layer instances; update via props, not by recreating layers each render.

## 11. Frontend Tests

- Unit: threshold debounce, timeline index logic, summary-sentence generator.
- Component: AnalyticsPanel renders API fixtures; AnomalyChart hidden when empty.
- Integration (MSW mocked API): select scene then see risk layer props with expected tile URL.
- Smoke (Playwright): load app, select field, move timeline, verify acres-at-risk value changes.
